# QR Code Component

A simple responsive QR code component built with **HTML** and **CSS** as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

## 📋 About the Project

This project is a simple QR code card that encourages users to improve their front-end development skills by visiting Frontend Mentor.

The page contains:

- A QR code image
- A heading
- A short description
- Responsive styling
- Attribution to Frontend Mentor

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- Responsive design
- Media queries
